# Per Greenhouse Pricing

## Current Model

Copperbeam prices Trellis One per greenhouse, not per sensor. Sanne fixed this
rule so grower invoices stay predictable when sensor counts change mid-season.

## Evidence

- `copperbeam-pricing-call` - Sanne prices Trellis One per greenhouse, not per
  sensor, so grower invoices stay predictable when sensor counts change.

## Use In Work

- Quote per greenhouse in proposals; never build a per sensor line item.

## Limits

Custom integrations outside the controller can still be quoted separately.
